# Калькулятор 1.0

1. Запустите класс `Main`.
2. Введите первый операнд.
3. Введите оператор: `+`, `-`, `*` или `/`.
4. Введите второй операнд.
5. Получите результат вычисления.

Пример:

```text
12.5
*
4
50.0
```

При делении на ноль калькулятор выведет сообщение об ошибке и предложит начать ввод заново.
