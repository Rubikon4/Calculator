# Калькулятор 1.0

1. Запустите класс `Main`.
2. Введите первый операнд.
3. Введите оператор: `+`, `-`, `*` или `/`.
4. Введите второй операнд.
5. Получите результат вычисления.
6. Продолжайте расчеты или введите `Q` для выхода.

Пример:

```text
12.5
*
4
50.0
```

При некорректном вводе калькулятор выведет сообщение об ошибке и повторит текущий этап ввода.
Команду `Q` можно ввести на любом этапе.
